# USAGE — read me first
1. Search before reading. Never read whole files when a search hit is enough.
2. SECRETS: all credentials live in LastPass. NEVER write a password, token,
   or API key into any file here. Reference secrets as pointers:
   "LastPass -> Personal -> <entry name>".
3. Routing new snippets: generic command, no internal details -> kbpub.
   Anything naming our network/hosts/services -> kbpriv. When in doubt, private.
4. nas/ contains static facts, not live data. Do not claim to know current
   free space or drive health; say it isn't tracked.
5. When appending cookbook entries, follow the frontmatter format in
   kbpub/cookbook/MANIFEST.md exactly.
